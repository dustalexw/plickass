plickass

Your offline music, with real names.

Plexamp saves downloads under random IDs. plickass copies them out as Artist / Album / 01 - Track, anywhere you like.

  • Live progress

Try it

Plexamp's downloads

    ~/Music/From Plexamp

      6 tracks, 3 albums, 2 artists ready to copy.

      Each Plexamp download folder keeps an index.json describing its tracks. plickass matches every random file name to its track and copies it with a real name. The demo uses made-up music.

      Your downloads, back in your hands

      Plexamp's offline files are perfectly good music, just with names like c3f9e1c0-77b2 and no extension. plickass fixes that in a couple of clicks.

      Finds Plexamp on its own

      It locates your Plexamp downloads folder and shows how many tracks, albums and artists are ready. Somewhere unusual? Click Browse….

      Real names, real folders

      Copies go into Artist / Album / 01 - Track with the right file extension, ready for any player or library.

      Never overwrites

      Files already in the destination are skipped, so you can run it again after every new batch of downloads.

      Read-only on Plexamp's side

      Your downloads are copied, never moved or changed, so Plexamp keeps working offline exactly as before.

      Live progress

      Every copied track is listed as it happens, then Show in Finder takes you straight to the results.

      Small and native

      A real macOS window with no extra frameworks. The copying is done by Python 3, which most Macs already have.

      Download

      One zip, one app. It runs on macOS 11 or later, on Apple silicon and Intel Macs.

      Install plickass

      1. Download the zip, unzip it and move plickass.app to Applications.
      2. First launch: the app isn't notarized by Apple, so open System Settings → Privacy & Security and click Open Anyway (or right-click the app and choose Open).
      3. After that it opens normally.
      Download plickass .zip

      If it asks for Python

      1. plickass uses Python 3 to do the copying. Most Macs have it through Apple's Command Line Tools.
      2. If plickass says it can't find Python, run this in Terminal, or install Python from python.org:
      xcode-select --install
      Python for macOS python.org

      Or build it yourself

      The app is a small JavaScript-for-Automation window around Python scripts, so building takes seconds. There's also a cross-platform command-line script for Windows and Linux.

      git clone https://github.com/dustalexw/plickass
cd plickass
./build.command                      # builds and opens plickass.app
python3 plexampDownloadCopier.py -d ~/Music/From\ Plexamp   # or just the script
